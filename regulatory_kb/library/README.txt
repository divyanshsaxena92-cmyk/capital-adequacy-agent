Drop RBI PDFs here (e.g. downloaded from rbi.org.in in your browser).
They are indexed into the knowledge base automatically when the app starts, and again on
"Index library folder" in the RBI Library page. Unchanged files are skipped.
Framework is guessed from the file name ("bank", "scb", "commercial" -> BANK, otherwise NBFC);
the effective date defaults to the file date and is flagged for confirmation.
